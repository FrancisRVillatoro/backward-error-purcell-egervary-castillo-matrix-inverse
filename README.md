# Growth, Pivoting, and Backward Error in the Purcell–Egerváry–Castillo Matrix Inverse

Reproducibility data and code associated with the paper

**Growth, Pivoting, and Backward Error in the Purcell–Egerváry–Castillo Matrix Inverse**

Francisco R. Villatoro

This repository contains computational reproducibility material only: source code, scripts, configurations, numerical reports, validation material, and data required to reproduce the reported computations.

## Reproducibility archive

Version: **1.1.0**

Zenodo v1.1.0 DOI:

    10.5281/zenodo.22706416

## Repository layout

- `code/` — numerical algorithms and analysis programs.
- `code/lapack_baseline/` — LAPACK explicit-inverse baseline and paired analysis.
- `code/validation/` — spectral-estimator validation.
- `config/` — computational configurations.
- `slurm/` — Slurm execution scripts.
- `reports/` — numerical reports, certificates, and validation summaries.
- `release_tools/` — reproducibility verification tools.
