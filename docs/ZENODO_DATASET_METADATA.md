## Description

Public reproducibility dataset for the numerical experiments accompanying the
manuscript “Backward Error of the Matrix Inverse in the
Purcell–Egerváry–Castillo Pivoting Transformation”.

The archive contains the frozen scientific code and configuration, the
canonical campaign manifest, all 999 recovered-task status records, an
independent certificate of the exact recovered population, compact analysis
data, the complete defect-replay record, final reports,
software-environment information, and SHA-256 provenance manifests.

The reported recovered population contains 14,686,763 matrices,
146,867,630 inverse records, and 1,321,808,670 solution records.

The full recovered inverse and solution CSV collection comprises 1,998 gzip
shards occupying 136,127,339,793 bytes. These working data are retained by
the author during peer review for possible reviewer-requested recalculation
or additional analysis and are not included in the public version 1.0.0
dataset.

The canonical manifest, deterministic task partition, all 999 task-status
records, the independent prefix certificate, and the bulk-file hash and size
manifests identify exactly the population analyzed in the manuscript.
