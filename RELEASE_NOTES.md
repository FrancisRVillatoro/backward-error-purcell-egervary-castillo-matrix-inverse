# Release 1.0.0

## Title

**Backward Error of the Purcell–Egerváry–Castillo Matrix Inverse**

## Scope

This release corresponds to the frozen computational record for the manuscript
“Backward Error of the Matrix Inverse in the Purcell–Egerváry–Castillo
Pivoting Transformation”.

It contains:

- the scientific implementation;
- deterministic campaign generators;
- canonical configurations and manifests;
- Slurm execution scripts;
- recovery and population-certification tools;
- theory and diagonal-dominance audits;
- defect-replay, compensation, and quadrature analyses;
- compact final reports;
- manuscript and supplementary LaTeX sources;
- provenance and integrity manifests.

## Computational record

The release documents:

- a mechanistic campaign with 18,744 matrix/right-hand-side configurations;
- a complete canonical design of 19,200,975 matrix cases;
- a recovered population of 14,686,763 complete matrices;
- 146,867,630 inverse records;
- 1,321,808,670 solution records;
- 999 independently certified recovered task prefixes.

## Retained bulk data

The complete recovered inverse and solution collection contains:

- 999 inverse gzip CSV shards;
- 999 solution gzip CSV shards;
- 1,998 files;
- 136,127,339,793 bytes.

These files remain retained by the author during peer review. They are not
included in the public version 1.0.0 asset, but their identities, byte sizes,
and SHA-256 digests are documented.

The canonical manifest, deterministic generation rules, 999 status records,
and independent prefix certificate identify exactly which matrices and record
groups constitute the population reported in the manuscript.
