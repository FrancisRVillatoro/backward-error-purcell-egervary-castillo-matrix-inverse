# Reproducibility data and code v1.1.0

Reproducibility material for:

**Growth, Pivoting, and Backward Error in the Purcell–Egerváry–Castillo Matrix Inverse**

Francisco R. Villatoro

Version 1.1.0 adds the prespecified 2496-matrix direct-SVD follow-up audit:

- deterministic reconstruction of ranks 0, 1000, and 1999 from all 832 balanced stochastic blocks;
- direct binary64 SVD reference evaluation for five Castillo variants and LAPACK;
- six-iteration estimator-accuracy summary;
- methodwise Castillo–LAPACK paired win fractions and median ratios;
- 2000-replication block-bootstrap confidence intervals;
- run specifications and audit-scope documentation.

The v1.0.0 frozen campaign remains unchanged and is the data source from which
the follow-up audit reconstructs its matrices.

This release contains computational reproducibility material only. It contains
no manuscript or journal-submission files.
